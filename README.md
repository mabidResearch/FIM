# Framework Integration Model (FIM)

This repository contains the public research artefact supporting the Framework Integration Model (FIM), developed to examine how heterogeneous cybersecurity framework obligations can be projected onto a stable incident response capability structure.

## Artefact

The principal artefact is:

`FIM_Mapping_Register_v3.2.xlsx`

The workbook contains the consolidated mapping register used for the FIM, including:

- the full six-framework × seven-pivot mapping register;
- relationship-aware classifications and rationales;
- source anchors and provenance information;
- descriptive coverage summaries;
- documentary triangulation and version records;
- the Secure Controls Framework (SCF) external documentary benchmark; and
- the associated primary-source review record.

## Framework Scope

The register covers:

- NIST Cybersecurity Framework 2.0
- ISO/IEC 27035
- MITRE ATT&CK
- COBIT 2019
- CIS Critical Security Controls v8.1
- ASD Essential Eight

The mapping comprises 42 primary framework-to-pivot relationships.

## SCF External Benchmark

SCF 2026.2 was introduced after construction of the primary FIM register as an external documentary comparator.

The final register records:

- Equivalent-scope substantive coverage: **59.5%**
- Inclusive substantive coverage: **83.3%**

Of the 28 sufficiently comparable cells, 21 were corroborated, six were partially corroborated and one produced a material divergence.

The divergence concerned Essential Eight — Preparation. The SCF comparison prompted a re-check of the primary Essential Eight source, after which the classification was conservatively revised from R2 to R3. All other FIM classifications remained unchanged.

The SCF comparison is an external documentary benchmark and should not be interpreted as empirical validation, independent inter-rater validation, or proof of the mapping.

## Evidentiary Status

The FIM mapping is researcher-led and based on documentary analysis of version-locked standards and framework sources.

The workbook is intended to provide an auditable and reproducible record of the mapping decisions, classifications, rationales and benchmark comparison.

Independent inter-rater assessment remains an appropriate future reliability extension.
